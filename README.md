# Project Lifecycle Safety Bot

AI assistant that answers construction safety questions using both:

- TXT safety documentation (RAG)
- CSV safety metrics (structured querying)

## Features

- Natural language safety queries
- Retrieval from safety documents
- CSV analytics for safety metrics
- Hybrid reasoning across data sources
- Interactive Streamlit UI

## Tech Stack

- Azure OpenAI GPT-4o
- LangChain
- FAISS Vector Database
- Pandas
- Streamlit

## Setup

1. Clone repository

git clone <repo_link>

2. Install dependencies

pip install -r requirements.txt

3. Run the application

streamlit run app.py
